# XAvatarWall

<div align="center">

## X(Twitter) Follower Avatar Wall Generator

一个用于制作 X（Twitter）粉丝纪念头像墙的工具。

自动整理粉丝头像，并生成一张高清粉丝纪念图片。

</div>

---

## 一键启动（适合零基础用户）

如果你电脑上 **没有安装 Python**，或者安装了但缺少依赖库（如 Pillow），或者运行时报错提示缺少模块，可以直接使用 **一键启动.bat** 文件。

- 双击 `一键启动.bat`
- 它会自动检测 Python 环境，若未安装则提示安装
- 自动安装所需的第三方库（pillow, requests, aiohttp, tqdm）
- 然后自动打开主程序界面，你可以从中选择需要使用的功能

> 此方式省去手动配置环境的步骤，推荐给不想折腾命令行的用户。

## 使用方法

本工具提供两种使用方式，根据你是否已有头像文件选择对应流程。  
你也可以直接双击 `一键启动.bat`，在界面中手动选择对应的功能（方式一或方式二），然后按照提示操作。

### 方式一：已有头像文件（自备图片）

如果你已经拥有粉丝头像图片（任意格式），可以双击 `一键启动.bat` 并手动选择“自备图片拼图”功能，或直接运行脚本按以下步骤操作：

1. 运行 `自备图片拼图.py` 脚本（或通过一键启动.bat 进入）。  
2. 在弹出的界面中选择存放头像的文件夹或选择图片文件（根据脚本设计）。  
3. 程序会自动进行图片查重，去除重复头像。  
4. 点击“生成”按钮，即可合成粉丝头像墙图片。  
5. 生成的图片将保存在指定输出目录（通常为 `output/`）。

### 方式二：无头像文件（需从 X 采集）

如果你尚未获取粉丝头像，可以双击 `一键启动.bat` 并手动选择“头像制作器”功能，或直接运行脚本并按以下步骤操作：

1. 安装篡改猴（Tampermonkey）浏览器扩展（如已安装可跳过）。  
2. 安装本工具提供的用户脚本：`一键下载头像.user.js`。  
3. 打开 X（Twitter）并进入你的**关注（Following）** 页面（或粉丝页面，根据脚本功能）。  
4. 点击页面右下角的**相机图标**，脚本将自动开始爬取粉丝头像。  
5. 爬取完成后，导出数据为 JSON 文件（脚本会提示导出）。  
6. 运行 `头像制作器.py` 脚本（或通过一键启动.bat）。  
7. 在脚本界面中导入刚才导出的 JSON 文件。  
8. 程序将自动下载所有头像，并直接合成粉丝头像墙图片。

> 提示：请合理使用脚本，遵守 X 平台规则，避免高频请求。
