# XAvatarWall 更新日志

## v1.0.0 — 全新浏览器扩展版本

### 一句话总结

从「Python 桌面工具 + 篡改猴脚本 + 手动导入 JSON」的旧版，全面升级为「Chrome / Edge / 狐猴浏览器扩展，输入用户名一键自动生成」的全新版本。

### 对比旧版（v0.7）

| 项目 | 旧版 v0.7 | 新版 v1.0.0 |
| --- | --- | --- |
| 运行方式 | 需要安装 Python，双击 BAT 启动器 | 安装浏览器扩展即可，无需任何运行环境 |
| 采集方式 | 安装篡改猴（Tampermonkey）脚本 | 扩展内置采集，自动打开 followers 页面 |
| 数据导出 | 手动点击「导出 JSON」 | 无需导出，数据自动保存 |
| 头像下载 | Python 脚本逐个下载 | 后台多线程并发下载（并发 8） |
| 图片生成 | 桌面程序单独生成 | 采集完成后自动生成 |
| 操作流程 | 采集 → 导出 JSON → 导入程序 → 下载 → 生成 | 输入用户名 → 点击开始 → 自动完成 |
| 跨域问题 | 头像 URL 直接使用 | 后台下载到本地缓存，规避 CORS |
| 排序方式 | 老粉 / 新粉两种 | X 显示顺序 / 老粉优先 / 新粉优先三种 |
| 界面风格 | 桌面 Tkinter 窗口 | 浅色主题的扩展弹窗与生成页 |

### 新增功能

- 浏览器原生扩展：采用 Manifest V3，兼容 Chrome、Edge、狐猴浏览器及其他 Chromium 内核浏览器。
- 图形化控制面板：在扩展弹窗中即可输入 X 用户名、选择生成数量、头像大小、排序方式和背景颜色。
- 一键自动完成：自动打开 `https://x.com/<用户名>/followers`，自动滚动加载、采集粉丝头像、下载头像并生成头像墙图片。
- 多线程下载：头像下载并发数提升至 8，大幅缩短等待时间。
- 下载容错机制：自动重试、跳过错误图片、按头像 URL 去重，避免重复下载。
- 断点续采：采集过程中刷新页面后可以继续，不会丢失已采集的数据。
- 数据自动保存：粉丝数据、配置和进度统一保存在 `chrome.storage.local`，关闭弹窗也能继续。
- 进度条显示：采集、下载、生成全程可视化进度提示。
- 自动排版：按 `cols = ceil(sqrt(n))`、`rows = ceil(n / cols)` 自动计算网格，支持任意数量头像。
- 图片输出优化：生成 `XAvatarWall.jpg`，JPEG 质量 95%，头像圆角处理更美观。

### 全新界面与视觉

- 所有页面统一为浅色主题，整体更清爽。
- 去除旧版界面中的 emoji，视觉更简洁统一。
- 生成图片默认使用浅蓝色背景（`#dbeafe`）。
- 图片顶部使用蓝色字体显示「恭喜我 N fo」。
- 图片底部显示署名「XAvatarWall · X@qiujiudev」。

### 移除的旧版依赖

- 不再需要安装 Python。
- 不再需要安装 Pillow、requests、aiohttp、tqdm 等第三方库。
- 不再需要安装篡改猴（Tampermonkey）。
- 不再需要手动导入、导出 JSON 文件。

### 使用变化

旧版流程：

```text
双击一键启动.bat
→ 安装篡改猴脚本
→ 打开 X 关注页
→ 点击相机按钮采集
→ 导出 JSON
→ 导入 Python 程序
→ 下载头像
→ 生成图片
```

新版流程：

```text
打开 XAvatarWall 扩展
→ 输入 X 用户名
→ 选择参数
→ 点击开始制作
→ 自动采集
→ 自动下载
→ 自动生成图片
```

### 对用户的好处

- 上手门槛更低：不用再关心 Python 环境和依赖库。
- 操作步骤更少：从旧版的多步骤手动操作，简化为一次点击。
- 运行更稳定：后台下载头像解决跨域问题，不再因 CORS 报错。
- 生成速度更快：多线程并发下载，效率明显提升。
- 体验更完整：自动完成、进度提示、断点续采、自动保存，让整个流程不再容易中断。
